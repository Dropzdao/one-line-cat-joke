Entry for the make.fun bounty **The One-Line Cat Joke That Lands**
($2, one winner, free to enter).

## The entry

> I asked my cat for emotional support; he walked across my keyboard, deleted my work, and left like he'd fixed everything.

One line, 121 characters — a cat joke with a setup and a turn that lands
on the last word. You ask for comfort; the cat "helps" by deleting your
work and strutting off proud of a job well done. No tired pun, no
wind-up, nothing to explain afterwards.

## How it works

`main.py` writes the line above to `/output/entry.txt`. Nothing else:
deterministic, no network, no input, no dependencies beyond Python 3.

```sh
python3 main.py
cat /output/entry.txt
```
